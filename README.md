# Telegram Chat Journal

Самостоятельный бот на Python и aiogram для одного владельца. Показывает правки, удалённые сообщения и архив выбранных личных чатов через кнопки Telegram.

## Как пользоваться

Отправь `/start`, чтобы появилось меню **Архив · Чаты · Настройки**. В архиве нажми на строку, чтобы открыть запись, посмотреть предыдущую версию или открыть вложение. Фильтры **Удалённые** и **Правки** показывают текущее состояние сообщений. Уведомления открывают последнюю запись или весь архив одним нажатием.

В **Настройках** можно включить запись, поставить её на паузу и очистить архив с подтверждением. Команды `/archive`, `/chats`, `/status`, `/show ID`, `/enable`, `/disable` и `/purge confirm` тоже поддерживаются.

## Самостоятельный запуск

Нужны Python 3.11+, [uv](https://docs.astral.sh/uv/getting-started/installation/) и отдельный бот от [@BotFather](https://t.me/BotFather). Включи у бота **Secretary Mode**.

1. Из каталога проекта установи зависимости и создай локальный файл настроек.

   ```sh
   uv sync --locked
   (umask 077; cp -n .env.example .env)
   ```

2. Впиши токен BotFather в `TELEGRAM_BOT_TOKEN`. Для нового бота запусти команду ниже, отправь показанную одноразовую строку ему в личку и впиши полученный `TELEGRAM_OWNER_ID` в `.env`.

   ```sh
   uv run --locked python -m journal_bot identify
   ```

3. Сгенерируй ключ. Впиши результат в `ARCHIVE_KEY_BASE64`.

   ```sh
   uv run --locked python -c 'import base64, secrets; print(base64.b64encode(secrets.token_bytes(32)).decode())'
   ```

4. Запусти бота одним процессом.

   ```sh
   uv run --locked python -m journal_bot
   ```

5. В Telegram открой **Настройки → Автоматизация чатов**. Добавь бота, выбери личные чаты и предупреди их участников об архивировании. Затем отправь боту `/start` и нажми **Настройки → Включить запись**.

`ARCHIVE_TIMEZONE` задаёт часовой пояс IANA для даты в интерфейсе. По умолчанию используется `UTC`. Например, можно указать `Asia/Almaty`.

Для перехода с v0.1.x останови процесс Node.js и запусти новую версию с теми же `ARCHIVE_DB`, `ARCHIVE_KEY_BASE64`, `TELEGRAM_OWNER_ID` и токеном. Python открывает старую SQLite напрямую и при первом запуске добавляет индекс для фильтров. Сохрани бэкап базы и ключ отдельно до обновления.

## Хранение и ограничения

- Запись начинается после включения и охватывает личные чаты, доступные через «Автоматизацию чатов». При удалении Telegram передаёт только ID сообщения. В журнале появляется удаление, если бот уже сохранил содержимое.
- SQLite хранит текст, названия чатов и `file_id` обычных вложений. Сами файлы остаются в Telegram. Открытие файла зависит от доступности `file_id` в Bot API. Одноразовые медиа, секретные чаты и сообщения с защитой от пересылки пропускаются.
- Срок по умолчанию составляет 7 дней с отправки сообщения. `ARCHIVE_RETENTION_DAYS` принимает значения от 1 до 90. Правки и удаления используют срок исходной записи.
- Содержимое в `data/archive.sqlite` шифруется AES-256-GCM. Для чтения базы нужен отдельный ключ. Храни ключ отдельно от резервной копии SQLite.
- Отключение автоматизации или замена ID подключения очищают архив и ставят запись на паузу. Очистка удаляет записи на сервере. Уже открытые записи можно удалить из лички с ботом средствами Telegram.

## Проверка

```sh
uv run --locked python -m unittest discover -s test -v
```

Тесты проверяют кнопки и бизнес-события через маршрутизатор aiogram с имитацией Telegram API. Для живой проверки отправь тестовое сообщение в выбранном чате, измени его, удали и открой запись кнопкой **Архив**.
